一、HTTP/HTTPS 代理拦截类

mitmproxy ★ ~37,000 Python 79.9% / TypeScript 14.7% MIT

功能概览

  • 交互式 SSL/TLS 拦截代理，支持 HTTP/1、HTTP/2、WebSocket、TCP[1]
  • 三种界面模式：mitmproxy（终端控制台）、mitmweb（Web UI）、mitmdump（无头命令行）
  • 实时拦截、修改、重放 HTTP 请求和响应
  • 强大的 Python 脚本/插件系统，支持自定义 addon 热加载
  • 支持反向代理模式、上游代理、透明代理
  • 内置 Flowfilter 过滤语言，精准筛选流量
  • 被超过 5,200 个项目依赖[1]

特色

三种交互模式并存：CLI 控制台适合快速调试、Web UI 适合可视化审查、mitmdump 适合自动化流水线集成。这是同类工具中独一无二的设计。
  • Python 插件生态极强，可编写 request/response 钩子完全控制代理行为
  • 对 HTTP/2 和 QUIC 支持业界领先，最新版本 v12.2.3（2026-05）
  • 活跃维护：2026年7月仍有频繁提交[1]

产品重心

面向开发者和安全测试人员的全方位 HTTP 代理工具。重心在于可编程自动化——通过 Python 脚本实现复杂的流量操控逻辑，是渗透测试、爬虫开发、API 调试的首选。同时兼顾交互式调试需求。

Whistle ★ ~19,000 JavaScript 94.1% MIT

功能概览

  • 基于 Node.js 的 HTTP/HTTPS/HTTP2/WebSocket/TCP 代理调试工具[2]
  • Web 管理界面（默认 http://127.0.0.1:8899），浏览器中直接抓包
  • 支持正则匹配、变量、分组规则配置
  • 支持 Mock 数据、请求转发、请求头修改、延迟注入、断网模拟
  • 支持 WebSocket 抓包、构造请求及修改数据
  • 内置 Weinre（远程 DOM 检查）、Console 日志查看、Composer 请求编辑
  • 丰富的插件体系，支持自定义扩展规则和界面[2]
  • 支持无界面 Linux 服务器环境部署

特色

规则系统极其灵活：类似 hosts 文件语法但功能强大得多，一行规则即可实现请求转发、Mock、延迟、Header 修改等多种操作。插件生态丰富，可作为 NPM 模块引用。
  • 一站式管理界面：抓包、规则、插件、Weinre/Console/Composer 集中管理
  • 提供桌面客户端 whistle-client，免大部分手动安装配置步骤
  • 中文文档极其完善，国内社区活跃
  • 活跃维护：2026年7月最新版本 v2.10.6[2]

产品重心

面向前端开发者的调试代理工具。重心在于规则驱动的流量操控——通过简洁的规则语法实现 Mock、转发、延迟注入等前端调试常见需求。插件化和客户端化降低了使用门槛，适合前端团队日常开发和移动端调试。

规则驱动插件生态Mock延迟注入Weinre跨平台客户端中文友好TCP

功能概览

  • 维护频率较低，功能相对稳定但更新慢

二、流量录制与回放类

GoReplay ★ ~19,200 Go LGPL-3.0 (核心) / 商业PRO

功能概览

  • 捕获生产环境实时 HTTP 流量并回放到测试环境[3]
  • 基于 libpcap 在网络接口层旁路监听，无需修改生产架构
  • 支持流量过滤、修改、速率限制
  • 支持 Kafka 输入/输出、Elasticsearch 集成
  • 支持 WebSocket 流量回放
  • 中间件系统允许用 Go 编写自定义处理逻辑
  • 支持 TCP 流量录制与回放

特色

非侵入式旁路监听：GoReplay 不是代理，而是在网络层旁听流量，对生产环境零影响、零延迟。这是与 mitmproxy/Whistle 等代理型工具的根本区别。
  • 被 GOV.UK、The Guardian、TomTom 等大型机构使用[3]
  • PRO 版本支持二进制协议（Thrift/ProtocolBuffers）、云存储、TCP 会话复制
  • 支持 Docker、Kubernetes 部署

产品重心

面向DevOps 和 QA 团队的流量录制回放工具。重心在于基于真实流量的持续验证——用生产环境的真实流量在测试/预发环境进行 Shadow 测试、回归测试和性能验证，提升发布信心。

非侵入式旁路监听Shadow测试KafkaElasticsearchTCPDockerK8s

三、网络协议分析类

Wireshark ★ ~7,000 (GitHub镜像) C / C++ / Lua GPL-2.0

功能概览

  • 全球最流行的网络协议分析工具（GUI 版）[4]
  • 实时捕获和离线分析网络数据包
  • 支持数千种网络协议的深度解析（TCP/UDP/ICMP/HTTP/DNS/TLS/SMB等）
  • 强大的显示过滤器（BPF 语法 + Wireshark 专有语法）
  • 支持色彩规则、协议分层展示
  • 统计与图表生成（IO 图表、端点统计、协议分布）
  • 命令行版 TShark 适合服务器环境
  • 支持 pcap/pcapng 文件格式读写

特色

行业标准级协议分析器：支持协议数量最多、深度协议解析能力无可匹敌。拥有丰富的 Dissector 生态，社区贡献的协议解析插件覆盖几乎所有已知协议。
  • 主代码仓库在 GitLab，GitHub 为镜像（实际用户量远超 star 数）
  • 极其活跃，持续更新
  • 不仅支持 HTTP，更擅长 TCP/UDP/DNS/TLS 等底层协议分析

产品重心

面向网络工程师和安全审计人员的专业协议分析工具。重心在于底层网络协议的深度解析——从网络层到应用层的全面覆盖。不适合 HTTP API 的快速调试，但在网络故障排查、安全审计、协议逆向分析领域无可替代。

协议解析BPF过滤IO图表TSharkpcap行业标准Dissector
Nmap ★ ~10,000 C / C++ / Python / Lua NPSL (类GPL)

功能概览

产品重心

面向网络安全工程师和渗透测试人员的扫描审计工具。重心在于网络资产发现与安全评估——从主机发现到服务指纹、从漏洞检测到利用验证的一站式框架。抓包只是其众多能力中的一部分。

功能概览

产品重心

面向渗透测试人员和安全研究者的攻击框架。重心在于网络层面的主动攻击——不仅仅是被动抓包，更能主动操控流量（ARP欺骗、DNS劫持、WiFi攻击）。适合红队作战和安全研究场景。

五、规则代理/翻墙类

Clash ★ ~48,200 (已删仓) Go 99.3% 已闭源

功能概览

  • 入站：HTTP、HTTPS、SOCKS5 服务器、TUN 设备
  • 出站：Shadowsocks(R)、VMess、Trojan、Snell、WireGuard 等多种协议

面向普通用户和开发者的科学上网工具。重心在于规则驱动的流量分流——让不同类型的网络请求走不同的出口。虽不是抓包工具，但其网络层流量处理架构值得参考。

八、产品定位象限分析

以「功能深度」为 X 轴（从基础代理到全功能框架）和「使用门槛」为 Y 轴（从零配置到专业运维）来分析各工具的定位：

象限特征代表工具
高深度 + 低门槛功能强大且易于上手Whistle、LightProxy
高深度 + 高门槛专业级全功能框架Wireshark、Bettercap、Nmap
低深度 + 低门槛轻量级简单工具GoProxy、Proxyee
垂直场景专注特定领域GoReplay（流量回放）、httpx（资产发现）、Clash（规则分流）

mitmproxy 处于特殊位置——功能深度高但 CLI 模式门槛较高、Web UI 模式门槛适中，横跨两个象限。
